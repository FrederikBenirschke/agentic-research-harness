# Choosing what to try next

- Hold several explanations of what you have seen, not one. Ask what each
  would predict that the others would not, and test that.
- Prefer the test that would change your mind most, not the one most likely
  to succeed.
- An idea that failed once may have failed for a fixable reason: too little
  data, the wrong form, the wrong measurement. Ask which before dropping it.
- If everything you have tried is a variation of one idea, try a different
  one before refining further.
- Read what others have found and tried (`search_notes`), and build on it or
  argue with it.
